# Portafolio — Alejandra Altamirano

Sitio de portafolio con estética cyberpunk (hero interactivo, lluvia estilo Matrix,
efecto de escritura, glitch text, zoom-out al hacer scroll). Construido en HTML,
CSS y JavaScript puro, sin frameworks ni build tools.

## Estructura

```
portafolio/
├── index.html          estructura del sitio
├── css/
│   └── style.css       todos los estilos del hero
├── js/
│   ├── typing.js        efecto de escritura del nombre
│   ├── matrix.js         lluvia de caracteres tipo Matrix
│   ├── particles.js      partículas flotantes de fondo
│   └── scroll.js         zoom-out del hero al hacer scroll
└── README.md
```

## Cómo verlo localmente

Solo abre `index.html` en el navegador. No requiere instalar nada.

## Cómo desplegarlo (gratis)

**GitHub Pages** (recomendado, más simple):
1. Sube esta carpeta a un repo de GitHub
2. Ve a Settings → Pages → selecciona la rama principal
3. Tu sitio queda en `https://tu-usuario.github.io/nombre-repo`
